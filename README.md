# 火星档案馆 · MARS ARCHIVE

华晨宇火星演唱会 2014—2026 全场次歌迷存档站。

## 打开方式

双击 `index.html` 即可。整站是纯静态页面，不需要安装任何东西，也不需要联网数据库。

## 目录说明

```
mars-archive/
├── index.html          页面结构
├── css/style.css       样式
├── supabase-schema.sql 共享后端建表语句（需接后端时才用）
└── js/
    ├── data.js    ← 你要改的就是这一个文件
    ├── store.js        本地存储（观演记录、照片、设备ID、共享标记）
    ├── config.js       共享后端密钥（默认空，开启共享才填）
    ├── backend.js      共享后端适配器（Supabase REST，无需 SDK）
    ├── app.js          页面逻辑
    ├── map.js          足迹地图
    └── china-geo.js    中国省界数据（随站自带，不联网）
```

## 怎么补数据（只需要动 `js/data.js`）

用记事本或 VS Code 打开 `js/data.js`，找到 `SHOWS` 里对应的那一场。

### 1. 补歌单

找到 `setlist:[]`，把歌名填进去，每首歌用中文引号包起来，逗号分隔：

```js
setlist:['虚幻与现实','我管你','斗牛','好想爱这个世界啊'],
```

### 2. 补官方视频

**只允许填官方来源**：华晨宇本人、华晨宇工作室、火星演唱会官方账号。

B 站官方投稿（从视频链接里复制 `BV` 开头那一串）：

```js
video:{ platform:'bilibili', bvid:'BV1xx411c7XX' },
```

微博 / 抖音 / 小红书官方视频（直接贴链接）：

```js
video:{ platform:'weibo', url:'https://weibo.com/xxxxx' },
```

没有官方视频就保持 `video:null`，页面会显示「官方影像待收录」并给出官方账号入口，不会出现任何非官方内容。

### 3. 补造型档案

造型按**年度**统一维护。在文件上方的 `TOURS` 里找到对应年份，改 `look` 那一行：

```js
{ year:2026, name:'火星乐园 2.0', ..., look:'白色纱质长袍，银色发饰' }
```

### 4. 新增一场演唱会

复制任意一行 `{ date:... }`，粘贴到对应年份的位置，改掉里面的内容即可。
`date` 必须写成 `'2026-08-15'` 这种格式，`province` 要写全称（例如 `'广东省'`、`'香港特别行政区'`）。

改完保存，刷新页面就生效。左上角的总场次、地图颜色、省份榜单都会自动重新计算，不用手动改数字。

## 三个页面

- **时间轴**：按年份分章，每年一段巡演概述 + 全部场次。点任意一场打开档案抽屉（场馆、舞台形态、造型、歌单、官方影像、我的照片）。
- **足迹地图**：全国省级行政区填色，颜色越亮代表场次越多。右侧是省份榜单和「尚未到达」清单。
- **我的火星**：歌迷自己的观演统计、场次清单和照片墙。

## 关于歌迷互动数据

标记的场次和上传的照片**默认只保存在使用者自己的浏览器里**（localStorage），不会上传到任何服务器，别人也看不到。

**共享是可选的、可随时撤回的**：用户在任意场次或照片上点「共享到回忆墙」后，该条内容才会同步到公共的「火星回忆墙」（所有人可见）。撤下开关即从回忆墙移除，但本机珍藏的记录仍在。共享仅含场次与照片，不含任何个人隐私信息。

照片会自动压缩到长边 1100px，每场最多 6 张。建议定期点「导出我的档案」生成备份文件，换电脑或清理浏览器后可以用「导入备份」恢复。

## 开启共享（火星回忆墙）

共享功能需要一个免费后端来保存所有人的共享内容。本项目使用 **Supabase**（免费额度足够一个粉丝站），不依赖任何付费服务。

**第 1 步 · 建项目**
打开 https://supabase.com 注册（可用 GitHub 登录），New Project，地区选就近（如 Southeast Asia），等待创建完成。

**第 2 步 · 跑建表语句**
进入项目后台 → **SQL Editor** → New Query，把本目录下的 `supabase-schema.sql` 全部内容粘贴进去，点 **Run**。这会建好 `attendance` / `photos` 两张表、行级安全策略、聚合查询函数，以及图片存储桶。

**第 3 步 · 填入密钥**
进入项目后台 → **Settings → API**，复制两项：
- `Project URL`（形如 `https://xxxx.supabase.co`）
- `anon public key`（Project API keys 里的 `anon` / `public`）

打开 `js/config.js`，把这两项分别填进去：

```js
window.APP_CONFIG = {
  SUPABASE_URL: 'https://xxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJhbGci...'
};
```

保存，刷新页面。此时时间轴每行、档案抽屉里的照片右上角都会出现「共享」按钮，回忆墙页也会开始显示所有人的共享内容。

> 国内访问 Supabase 偶尔偏慢；若实测卡顿，可改用 Cloudflare（Workers + D1 + R2），代码已抽象在 `js/backend.js`，替换适配器即可，前端无需改动。

## 素材合规

全站图片与视频仅收录以下来源：华晨宇本人、华晨宇工作室、火星演唱会官方账号（微博 / 小红书 / 抖音 / 哔哩哔哩）。页面所有装饰性视觉均由代码生成，不使用任何第三方图片。

地图为中国省界 SVG（标准行政区划数据随站自带，含台湾省、香港特别行政区、澳门特别行政区及南海诸岛九段线），不依赖任何外部地图服务，符合国家地图管理规范。

## 数据来源

场次信息整理自官方公告、百度百科「华晨宇火星演唱会」词条及歌迷公开整理资料，共 **87 场 / 24 城 / 20 个省级行政区**（玉溪站已取消，未计入）。如与官方发布有出入，以官方为准。

## 开源说明（本仓库）

- 本仓库为**产品源码**，仅含前端代码、87 场场次数据（`js/data.js`）与共享后端建表语句（`supabase-schema.sql`）。
- **不含造型图片**：造型图（`looks/`）因版权原因不随仓库分发，已在 `.gitignore` 中排除。clone 后造型档案区为空属正常，接入自己的图片即可。

- 数据准确性：歌单为歌迷整理版（非官方），场次信息以官方公告为准。
